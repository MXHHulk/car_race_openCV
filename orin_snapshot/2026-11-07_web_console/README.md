# 穩定版 3 + 網頁控制台（2026-11-07，網頁服務獨立）

行車參數和穩定版 3（`stable-v3`）一樣，多了網頁控制台：`webui.py`（新）、`main.py`（接上網頁、每趟紀錄）、
`webctl.py`（新，獨立網頁服務）、`config.yaml`（新增 `web:` 段）、`hilltop.py`（下坡卡住加推）。
2026-11-07 在車上用真鏡頭、主程式 `--dry-run`（不接馬達）測過整套流程，還沒實際開車測。

## 怎麼用（網頁和主程式分開啟動）

1. 先在車上啟動**網頁服務**（不會開鏡頭、不會動車）：`python3 webctl.py`，終端機會印出網址。
2. 手機或電腦連同一個 Wi-Fi（R18-AIRACE），開 `http://192.168.0.116:8000/`。
3. 網頁上按「啟動主程式」（約 5–10 秒鏡頭、IMU 準備好），或照舊在終端機 `python3 main.py`（網頁一樣看得到、控制得到，但只能從終端機關）。
4. 主程式在跑時：即時畫面、**開始 / 停止**、勾選**紀錄**（這一趟寫 `logs/run_*.csv` + `run_*.mp4`）、
   **起跑模式**（按開始後等中控台綠燈才出發）；行駛中（含等綠燈）勾選不能改。主程式沒在跑時勾選先記住，啟動時帶過去。
5. 「關閉主程式」會先停車再結束；網頁啟動的主程式輸出在 `logs/console_*.txt`。

主程式的控制埠只開在本機 `127.0.0.1:8001`（`web.host` / `web.port`），手機一律走 webctl 的 8000。
測試不接馬達：`python3 webctl.py --main-arg=--dry-run`。

另外這版修了下坡卡住：對準 / 下坡卡住（畫面變化 < 1.5 超過 0.5 s）就 1 s 內加到 60%，要畫面變化 > 3 才算動起來
（103921 坡口卡住時變化在 0.4–1.4 之間跳，舊門檻一直被重置，只推到 40% 卡 5 秒）。
