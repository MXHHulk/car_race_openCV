# 操作手冊

電腦上的指令都在 `D:\coding_place\car` 執行，Orin 上的程式在 `~/orin_tools`。Orin 的 IP 可能會變，用 `hostname -I` 查。

## 每次上車的流程

1. **開機：** 在 Orin 上執行 `sudo jetson_clocks`。
2. **傳程式：** 只傳有改的檔案，不要整個資料夾覆蓋，Orin 的 `config.yaml` 才是實際在用的。

```bash
scp orin_tools/lane/*.py jetson@<ORIN_IP>:~/orin_tools/lane/
```

3. **檢查鏡頭：** 車子摔過或碰過才需要。

```bash
cd ~/orin_tools && python3 tools/cam_align.py
```

4. **跑車：** 加 `--record` 才會存影像，按 Enter 出發、再按 Enter 停車、`q` 離開。

```bash
cd ~/orin_tools/lane && python3 main.py --record
```

5. **抓紀錄：** 依日期放進 `orin_tools/logs/`。

```bash
scp "jetson@<ORIN_IP>:~/orin_tools/logs/run_YYYYMMDD_*" orin_tools/logs/YYYY-MM-DD/
```

## 第一次設定

### 1. 燒錄 BMduino

正式韌體在 `firmware/bmduino_motor/`，診斷韌體在 `firmware/diagnostics/`。

1. Arduino IDE 安裝 BMduino 開發板套件，開發板選 **BMduino UNO**。
2. USB 要插 **e-Link32 那個口**（電腦上會出現 HID 裝置與 COM6）。插錯口會出現 `can't enumerate any e-Link32`（exit status 30）。
3. 開啟要用的 `.ino` 並上傳，序列埠監控視窗設 115200。

### 2. 設定 Orin（只需做一次）

```bash
sudo apt install -y python3-serial
sudo usermod -aG dialout $USER        # 執行後要重新登入 SSH
sudo systemctl disable --now nvgetty  # 避免 UART 被序列埠登入服務佔用
```

從電腦把程式傳到 Orin：

```bash
scp -r orin_tools jetson@<Orin的IP>:~/
```

### 3. 測試 UART 通訊

BMduino 燒錄 `bmduino_uart_test.ino` 後，在 Orin 上執行：

```bash
cd ~/orin_tools
python3 uart_test.py -p /dev/ttyTHS1 -b 115200
```

最後顯示 `PASS` 就代表雙向通訊正常。

### 4. 控制馬達與舵機（⚠ 先把車架高）

BMduino 燒錄 `bmduino_motor.ino` 後，在 Orin 上執行：

```bash
python3 motor_cmd.py --fwa 20 -t 1                # 前輪右轉 1 秒
python3 motor_cmd.py --bwl 30 --bwr 30 -t 2       # 後輪前進 2 秒
python3 motor_cmd.py --teleop                     # 鍵盤遙控：W/S 速度、A/D 轉向、空白鍵停車、Q 離開
```

韌體開頭的設定區可以調整：`SERVO_CENTER_US`（前輪置中）、`SERVO_US_MIN` / `SERVO_US_MAX`（轉向行程）、`SERVO_INVERT`、各馬達的 `invert`、`MIN_DUTY`（起動死區）。

### 5. 調校鏡頭（每換一個場地就做一次）

```bash
python3 cam_tuner.py        # 電腦或手機瀏覽器開 http://<Orin的IP>:8080
```

依頁面上的建議流程：自動找曝光 → 拉條微調到檢查全綠 → 調 ROI → 車放直線正中央按「建立基準」→「存到 config」。
不同場地可以「存成設定檔」（`cam_profiles/`），下次直接載入。鏡頭同時只能給一支程式用，執行前先關掉其他用鏡頭的程式。

### 5-1. 檢查鏡頭視角

```bash
python3 lane_view_check.py --selftest                          # 先用合成畫面驗證演算法
python3 lane_view_check.py                                     # 即時檢查，瀏覽器開 http://<Orin的IP>:8080
python3 lane_view_check.py --frames 60 --save-baseline baseline.json   # 車停在平坦直線正中央，建立基準
python3 lane_view_check.py --baseline baseline.json --label left --frames 60 --out runs/left
```

`--source` 也可以改讀影片、單張圖片或整個資料夾，方便離線開發。

### 6. 循跡主程式

```bash
sudo apt install -y python3-yaml
cd ~/orin_tools/lane
```

1. 量好車子尺寸填進 `config.yaml` 的 `geometry`（鏡頭高度、鏡頭到後輪軸距離、軸距、路寬）。
2. 車停在平坦直線正中央建立基準（放在 `orin_tools/baseline.json`，config 預設讀這裡）：
   `python3 ../lane_view_check.py --frames 60 --save-baseline ../baseline.json`
3. **架高測試**：`python3 main.py`。待命時前輪會跟著畫面轉（`idle_steer`），用手拿白線黑紙在鏡頭前移動，確認轉向方向正確；按 Enter 出發後拔掉 UART 線，輪子要在 0.5 秒內停。
4. 實車低速：`python3 main.py`，按 Enter 出發 / 停車，`q` 離開。瀏覽器開 `http://<Orin的IP>:8080` 看除錯畫面，每次執行的紀錄在 `orin_tools/logs/`。

離線開發（在 `orin_tools` 底下執行，電腦上也能跑）：

```bash
python3 tools/sim_drive.py --track s_curve        # 閉迴路模擬：s_curve / tight / slope
python3 tools/record.py runs/track.mp4             # Orin 上推車錄影
python3 lane/main.py --dry-run --go --source runs/track.mp4 --save-video out.mp4
```

已知限制：鏡頭只看得到「相對車身」的坡度變化，爬坡途中會把坡頂判成下坡、下坡途中會把坡底判成上坡。目前用 `slope_memory` 時間窗避免爬坡中減速，要準確需要加 IMU 或編碼器里程。

## 通訊協議

依《UART 通訊協議書》：ASCII 封包，8N1，115200，結尾為單一 `\n`（0x0A）。

```
Orin → BMduino   <CMD,fwa 0,bwl 30,bwr 30,cs 18>\n
BMduino → Orin   <STA,S1 -1,cs 34>\n
```

| 欄位 | 意義 | 範圍 |
|---|---|---|
| `fwa` | 前輪轉角，負值左轉、正值右轉 | −90 ~ 90 度（韌體再限制在 1100~1920µs 的行程內） |
| `bwl` / `bwr` | 左 / 右後輪速度，正值前進 | −100 ~ 100 % |
| `S1` | 感測器距離，未接感測器時為 −1 | mm |
| `cs` | `<` 與 `>` 之間、扣掉 `,cs XX` 的內容逐字元 XOR，兩位大寫十六進位 | 00 ~ FF |

安全機制：

- BMduino 上電時馬達停止。
- 超過 500 ms 沒收到有效 CMD 就停止馬達，舵機維持最後角度。
- `motor_cmd.py` 結束或按 Ctrl+C 時會送出停車指令。

## 疑難排解

| 現象 | 處理方式 |
|---|---|
| 上傳失敗 `can't enumerate any e-Link32` | USB 改插 e-Link 那個口 |
| `/dev/ttyTHS0` 不存在 | 這台 Orin 的 Pin 8/10 是 `/dev/ttyTHS1` |
| `Permission denied` | 加入 `dialout` 群組後要重新登入 SSH |
| Orin 完全沒收到資料 | 檢查 TX/RX 是否交叉、是否共地；量 BMduino D21 閒置電壓；用 Pin 8 ↔ Pin 10 短接測試 Orin RX 是否正常 |
| 通訊正常但輪子不轉 | 燒錄 `firmware/diagnostics/bmduino_motor_diag` 逐腳檢查；確認驅動板有 12V |
| 只有某些方向會轉 | 燒錄 `firmware/diagnostics/bmduino_pca_scan`，找出 IN1~IN4 實際接在哪個通道（目前已知為 CH4~CH7） |
| 前輪左右相反 | 韌體將 `SERVO_INVERT` 改成 `true` |
| 給正值馬達卻倒轉 | 韌體將該馬達的 `invert` 改成 `true` |
| 低速時馬達不轉 | 調高 `MIN_DUTY`，例如 60 |
| 跑車時 fps 很低（紀錄檔 `fps` 欄、終端機狀態列） | 執行 `python3 tools/cam_fps.py` 分段量測。已知原因：鏡頭緩衝設 1 張會掉一半幀（已修正）、曝光時間超過 330、Orin 沒執行 `sudo jetson_clocks` |
| 舵機不動但馬達會動 | PCA9685 正常，查舵機電源 V+、舵機線與機構；目前舵機接 CH15 |
| 摔車後走線變差 | 跑 `python3 tools/cam_align.py`，把車身木板調到第 367 列（±1） |
