# `main.py --record` 程式運作說明

這份文件說明車子跑起來時，程式做什麼、什麼情況會切換動作，以及參數怎麼調。

參數值以 2026-11-01 最後一次貼上的 Orin 設定為準。實際值請看 Orin 上的 `~/orin_tools/lane/config.yaml`。

## 一、啟動時做什麼

在 `~/orin_tools/lane` 執行：

```bash
python3 main.py --record
```

1. 讀取 `config.yaml`，並設定鏡頭曝光等參數。
2. 開啟鏡頭和 UART。
3. 載入 `../baseline.json`，用來把畫面換算成實際距離。
4. 開啟除錯畫面 `http://<ORIN_IP>:8080`。
5. 建立紀錄檔 `~/orin_tools/logs/run_日期_時間.csv`。
6. 收到第一張畫面時，開始錄同名的 `.mp4`。
7. 進入 IDLE，**後輪不動**，但前輪會跟著畫面轉。

| 按鍵 | 狀態變化 |
| --- | --- |
| Enter | IDLE → RUN，出發 |
| Enter | RUN 或 LOST → STOP，停車 |
| Enter | STOP → IDLE，回到待命，要再按一次才出發 |
| q 再按 Enter | 結束程式，存好紀錄和影片 |

`--record` 只多存原始影片，不影響控制。沒加時只有 CSV，事後沒有畫面可以查。

## 二、每張畫面做的事

約每秒 30 次，依序執行：

1. **取畫面：** 只取最新一張。有 `--record` 就先寫入影片。
2. **找線：** `vision.py` 找出左右白線，換算成車身座標，算出中線、偏移和曲率。
3. **更新狀態：** 判斷 RUN、LOST、STOP。
4. **算前輪：** Pure Pursuit 朝中線前方的目標點轉向，再加積分修正。
5. **算速度：** 依前輪角度決定直線或彎道速度。
6. **卡住與車頭：** `stall.py` 判斷卡住或進坡，`yaw.py` 更新車頭角度。
7. **爬坡判斷：** `hilltop.py` 決定是否進入爬坡模式。
8. **路段限制：** 坡道限制前輪，下坡前限制前輪和速度。
9. **路口動作：** 左轉、直走、對準、右轉期間，直接覆蓋前輪和速度。
10. **決定後輪：** 卡住加速中或爬坡中兩輪同速，其他情況依前輪角度用差速。
11. **送出與記錄：** UART 每秒 20 次送給 BMduino，並寫一行 CSV。

## 三、四種狀態

| 狀態 | 意思 | 車子行為 |
| --- | --- | --- |
| IDLE | 待命 | 後輪 0，前輪跟著畫面轉 |
| RUN | 正常行駛 | 循線 |
| LOST | 看不到線 | 維持最後轉角、減速 |
| STOP | 停車 | 速度 0 |

| 觸發 | 結果 |
| --- | --- |
| RUN 中完全看不到線 | RUN → LOST，路口動作期間不會切換 |
| LOST 中重新看到線 | LOST → RUN |
| LOST 超過 0.3 秒 | STOP |
| LOST 超過 1 秒，且在爬坡或直走結束後 6 秒內 | STOP，避免停在坡上 |
| 超過 0.5 秒沒收到 BMduino 回報 | STOP |
| 1 秒沒有新畫面 | STOP |
| 按 Enter | 見第一節 |

BMduino 也有自己的保護：0.5 秒沒收到有效指令，就自動停馬達。

## 四、跑一圈的流程

```
出發 → 平地循線 → 進坡判斷 → 爬坡模式 → 看到虛線 → 左轉 → 直走
     → 對準下坡 → 落地 → 右轉 → 回到循線 → 下一圈
```

### 平地循線

- 前輪小於 8° 時用 `v_straight`，大於 24° 時用 `v_curve`，中間平滑過渡。
- 前輪打大時馬上減速，回正後約 0.6 秒慢慢加速。
- 前輪超過 25° 才開差速，超過越多差越大。
- 右彎時目標往內側靠，避免進坡時貼著左邊。

### 卡住與進坡

| 條件 | 動作 |
| --- | --- |
| 前輪 ≥ 40°，且最近 3 張畫面變化 < 4 | 馬上加速 15%，關差速 |
| 前輪 ≥ 36°，且最近 5 張畫面變化 < 1.6 | 馬上加速 15%，關差速 |
| 0.5 秒畫面變化中位數 < 0.6，持續 0.5 秒 | 判定卡住，每秒加 25%，最多 45% |

卡住時前輪不動，積分暫停。除了爬坡模式，總速度不超過 `total_max`。

### 爬坡模式

**進入條件要全部成立：**

- 卡住加速 ≥ 10%。
- 這次卡住發生在出發 3 秒後。
- 上次爬坡結束已超過 20 秒。

**爬坡中：**

- 速度固定 50%，兩輪同速。
- 不用右彎靠內，畫面不平行時只看左線。
- 加速退掉後，前輪限制 ±18°，並用車頭角度修正。
- 右線像素位置小於 500 時，不准往右打，並往左修，最多 −30°。
- 加速退掉 7 秒後結束爬坡模式。

### 路口左轉

- 加速退掉 4.5 秒後開始找虛線。
- 連續 2 張看到 2 塊以上方塊，就算看到虛線。
- 虛線到畫面第 320 列時左轉。看到後最多等 0.6 秒。
- 都沒看到時，加速退掉 9.8 秒後直接左轉。
- 前輪 −40°，速度 35%，車頭轉到 66° 或轉滿 2 秒就回正。回正後車頭還會再滑。

### 直走、對準、右轉

| 階段 | 時間 | 動作 |
| --- | --- | --- |
| 直走 | 3 秒 | 維持車頭 96°，速度 35% |
| 對準 | 到落地前 | 維持車頭 75°，速度 30%，不看線 |
| 右轉 | 最多 3 秒 | 前輪最多 +36°，車頭轉到約 38° 交回循線 |

直走結束 5 秒後，畫面變化超過 20 就算落地。到 6.8 秒還沒偵測到，也會直接右轉。

路口動作完成後 60 秒內不會再做一次，下一次爬坡才算下一圈。

## 五、遇到什麼情況，程式怎麼反應

| 情況 | 程式反應 |
| --- | --- |
| 只看到一條線 | 判斷是左線或右線，用路寬推算中線 |
| 兩條線太靠近 | 當成同一條線 |
| 完全看不到線 | 維持最後轉角減速，太久就停車 |
| 車子卡住 | 兩輪加速推出去 |
| 坡道上偏移突然跳動 | 先不採信，連續 6 張才接受 |
| 坡道靠上右側 | 右線保護往左修 |
| 鏡頭沒有畫面 | 停車 |
| 通訊中斷 | Orin 和 BMduino 都會停車 |

## 六、參數怎麼調

每次只改一個，改動幅度要小，跑完再看紀錄。

### 速度

| 參數 | 目前 | 調大 | 調小 | 什麼時候調 |
| --- | --- | --- | --- | --- |
| `v_straight` | 55 | 直線更快，較容易蛇行 | 較穩，但變慢 | 直線搖晃就調小 |
| `v_curve` | 36 | 彎道更快，較容易壓外側線 | 較穩，但變慢 | 壓線或進坡撞左側就調小 |
| `total_max` | 50 | 起步和進坡更有力，但可能暴衝 | 起步較穩，但可能推不動 | 起步衝出去就調小 |
| `hilltop.v_min`、`v_max` | 50 | 爬坡更快，隆起處較不穩 | 較穩，但太低會爬不上去 | 坡道不穩就調小 |
| `down_v` | 30 | 下坡前較快，風險高 | 較穩，但太低可能卡住 | 下坡容易衝出去就調小 |
| `speed` | 35 | 路口動作較快 | 較穩 | 左轉位置不穩時調小 |

### 轉向

| 參數 | 目前 | 調大 | 調小 | 什麼時候調 |
| --- | --- | --- | --- | --- |
| `lookahead` | 0.45 | 較平順，但會切內線、轉得晚 | 反應快，但容易搖 | 全程都搖才動 |
| `straight_ld` | 0.12 | 直線更穩，出彎較慢 | 反應快，但可能蛇行 | 直線搖就調大 |
| `down_ld` | 0.15 | 下坡前較不晃，但轉得晚 | 反應快，但較晃 | 下坡前搖晃時調大 |
| `k_i` | 60 | 長彎較不偏外，但可能過修 | 較不過修，但會偏外 | 長彎一直偏外才調大 |
| `fwa_limit` | 44 | 可以打更大角，機構負擔大 | 舵機較安全，但轉不過急彎 | 通常不動 |
| `inner_bias.k` | 0.10 | 右彎更靠內 | 較靠中間 | 進坡貼左才調大 |
| `diff_from` | 25 | 差速較晚介入，直線較穩 | 轉彎力道大，但可能晃 | 彎道轉不過才調小 |

### 坡道

### 只在特定情況動

| 參數 | 用途 |
| --- | --- |
| `lost_timeout` | 平地看不到線多久停車，調大較不易中斷，但開出賽道時反應慢 |
| `exposure_time_absolute` | 曝光，太大會掉幀，不要超過 330 |
| `roi_top`、`roi_bottom` | 畫面使用範圍，改了要重建基準 |
| `cam_height`、`lane_width`、`wheelbase` | 實際尺寸，量好後不要隨便改 |

## 七、調參步驟

1. 先看問題發生在哪個路段。
2. 查第六節，只改一個參數。
3. 用 `grep` 確認 Orin 的設定有改到。
4. 跑車時加 `--record`。
5. 抓回 CSV 和影片，比對改之前的結果。
6. 穩定後才提高速度。提速後，爬坡相關時間也可能要跟著調。

**摔車或碰撞後，先跑 `tools/cam_align.py` 檢查鏡頭。** 鏡頭歪了，調參數都沒有用。

## 八、終端機訊息

每秒會印一行：

```
RUN  線1.0 偏 -4.2cm 曲率+0.00 straight/flat → fwa   +8 速度  54/ 54  30.0 fps  處理 7.5 ms
```

| 欄位 | 意思 |
| --- | --- |
| 線 | 1.0 是兩條線，0.5 是一條線，0 是看不到 |
| 偏 | 中線相對車子的位置，正值是中線在左 |
| fwa | 前輪角度，負左正右 |
| 速度 | 左輪 / 右輪 % |
| fps | 應該接近 30 |

常見訊息：

| 訊息 | 意思 |
| --- | --- |
| `[stall] 畫面不動` | 開始卡住加速 |
| `[hilltop] 卡住加速到 …` | 進入爬坡模式 |
| `[junction] 坡頂路口` | 開始左轉 |
| `[junction] 左轉 X 秒結束，車頭轉了 Y°` | X 應該小於 2.0 |
| `[junction] 下坡到底` | 開始右轉 |
| `⚠ 鏡頭只有 … fps` | 曝光太長或系統太慢 |

## 九、紀錄檔怎麼看

| 欄位 | 內容 |
| --- | --- |
| `state` | 狀態 |
| `confidence` | 線的狀況 |
| `offset` | 偏移，公尺 |
| `fwa` | 前輪角度 |
| `bwl`、`bwr` | 左右後輪速度 |
| `motion` | 畫面變化，越大代表車動越快或顛簸 |
| `boost` | 卡住加速 |
| `hill` | `climb` 代表爬坡模式 |
| `junction` | `turn`、`straight`、`align`、`bend` |
| `yaw` | 累積車頭角度，負值代表往右轉 |
| `bias` | 右彎往內側靠的量 |
| `fps` | 影像速度 |
