main.py --record 程式運作說明

車子跑起來時程式做什麼、什麼情況會切換動作、參數怎麼調，以及每個程式檔的關鍵程式碼。

參數值以 2026-11-01 最後一次貼上的 Orin 設定為準。實際值請看 Orin 上的 ~/orin_tools/lane/config.yaml。電腦上的 config.yaml 有些功能是關的，不是實際跑車用的版本。

一、啟動時做什麼

在 ~/orin_tools/lane 執行：

python3 main.py --record
  1. 讀取 config.yaml，並設定鏡頭曝光等參數。
  2. 開啟鏡頭和 UART。
  3. 載入 ../baseline.json，用來把畫面換算成實際距離。
  4. 開啟除錯畫面 http://<ORIN_IP>:8080。
  5. 建立紀錄檔 ~/orin_tools/logs/run_日期_時間.csv。
  6. 收到第一張畫面時，開始錄同名的 .mp4。
  7. 進入 IDLE，後輪不動，但前輪會跟著畫面轉。
按鍵狀態變化
EnterIDLE → RUN，出發
EnterRUN 或 LOST → STOP，停車
EnterSTOP → IDLE，回到待命，要再按一次才出發
q 再按 Enter結束程式，存好紀錄和影片

--record 只多存原始影片，不影響控制。沒加時只有 CSV，事後沒有畫面可以查。

其他選項：--dry-run 不開序列埠、--source 影片.mp4 用影片重播、--go 啟動後直接出發、--no-stream 不開除錯畫面、--save-video 存疊圖影片。

二、每張畫面做的事

約每秒 30 次，依序執行（全部在 Pilot.step() 裡，見程式碼導讀）：

  1. 取畫面：只取最新一張。有 --record 就先寫入影片。
  2. 找線：vision.py 找出左右白線，換算成車身座標，算出中線、偏移和曲率。
  3. 更新狀態：判斷 RUN、LOST、STOP。
  4. 算前輪：Pure Pursuit 朝中線前方的目標點轉向，再加積分修正。
  5. 算速度：依前輪角度決定直線或彎道速度。
  6. 卡住與車頭：stall.py 判斷卡住或進坡，yaw.py 更新車頭角度。
  7. 爬坡判斷：hilltop.py 決定是否進入爬坡模式。
  8. 路段限制：坡道限制前輪，下坡前限制前輪和速度。
  9. 路口動作：左轉、直走、對準、右轉期間，直接覆蓋前輪和速度。
  10. 決定後輪：卡住加速中或爬坡中兩輪同速，其他情況依前輪角度用差速。
  11. 送出與記錄：UART 每秒 20 次送給 BMduino，並寫一行 CSV。

四、跑一圈的流程

出發→平地循線→進坡判斷→爬坡模式→看到虛線→左轉→直走→對準下坡→落地→右轉→回到循線→下一圈

平地循線

  • 前輪小於 8° 時用 v_straight，大於 24° 時用 v_curve，中間平滑過渡。
  • 前輪打大時馬上減速，回正後約 0.6 秒慢慢加速。
  • 前輪超過 25° 才開差速，超過越多差越大。
  • 右彎時目標往內側靠，避免進坡時貼著左邊。

卡住與進坡

條件動作
前輪 ≥ 40°，且最近 3 張畫面變化 < 4馬上加速 15%，關差速
前輪 ≥ 36°，且最近 5 張畫面變化 < 1.6馬上加速 15%，關差速
0.5 秒畫面變化中位數 < 0.6，持續 0.5 秒判定卡住，每秒加 25%，最多 45%

卡住時前輪不動，積分暫停。除了爬坡模式，總速度不超過 total_max。

爬坡模式

進入條件要全部成立：

  • 卡住加速 ≥ 10%。
  • 這次卡住發生在出發 3 秒後。
  • 上次爬坡結束已超過 20 秒。

爬坡中：

  • 速度固定 50%，兩輪同速。
  • 不用右彎靠內，畫面不平行時只看左線。
  • 加速退掉後，前輪限制 ±18°，並用車頭角度修正。
  • 右線像素位置小於 500 時，不准往右打，並往左修，最多 −30°。
  • 加速退掉 7 秒後結束爬坡模式。

路口左轉

  • 加速退掉 4.5 秒後開始找虛線。
  • 連續 2 張看到 2 塊以上方塊，就算看到虛線。
  • 虛線到畫面第 320 列時左轉。看到後最多等 0.6 秒。
  • 都沒看到時，加速退掉 9.8 秒後直接左轉。
  • 前輪 −40°，速度 35%，車頭轉到 66° 或轉滿 2 秒就回正。回正後車頭還會再滑。

直走、對準、右轉

階段時間動作
直走3 秒維持車頭 96°，速度 35%
對準到落地前維持車頭 75°，速度 30%，不看線
右轉最多 3 秒前輪最多 +36°，車頭轉到約 38° 交回循線

直走結束 5 秒後，畫面變化超過 20 就算落地。到 6.8 秒還沒偵測到，也會直接右轉。

路口動作完成後 60 秒內不會再做一次，下一次爬坡才算下一圈。

七、調參步驟

  1. 先看問題發生在哪個路段。
  2. 查第六節，只改一個參數。
  3. 用 grep 確認 Orin 的設定有改到。
  4. 跑車時加 --record。
  5. 抓回 CSV 和影片，比對改之前的結果。
  6. 穩定後才提高速度。提速後，爬坡相關時間也可能要跟著調。
摔車或碰撞後，先跑 tools/cam_align.py 檢查鏡頭。鏡頭歪了，調參數都沒有用。

def keyboard(pilot, quit_evt):
    while not quit_evt.is_set():
        line = sys.stdin.readline()
        if line.strip().lower() == "q":
            quit_evt.set()
        else:

main.py：Pilot.step()

1. 狀態轉移。坡道上或剛下坡時，看不到線可以撐比較久（down_lost_s），避免停在坡上。

res = self.res = self.det.process(frame)          # 找線
if self.state in (RUN, LOST) and sta_age > s["sta_timeout"]:
    self.stop("超過 0.5 秒沒收到 STA")
if self.state == RUN and res.confidence == 0 and not self.junc.active:
    self.state, self.t_lost = LOST, t
    self.v_lost = max(c["v_min"], self.ctl.v * s["lost_speed_factor"])
elif self.state == LOST:
    if res.confidence > 0:
        self.state = RUN
    elif t - self.t_lost > (down_lost_s if 爬坡中或剛下坡 else lost_timeout):
        self.stop("找不到線")

2. 設定控制器的旗標。卡住時暫停積分、爬坡關掉右彎靠內、下坡前看遠一點。

stuck = self.state == RUN and self.stall.med < self.stall.thresh and self.ctl.v > 0
self.ctl.hold_i = stuck                           # 卡住時積分不累積
self.ctl.no_bias = self.hill.active               # 爬坡不靠內
if self.junc.after_turn(t, self.junc.post_s):
    self.ctl.hold_i = True                        # 下坡前線不可靠，積分也暫停
if 路口動作結束後 down_s 秒內:
    self.ctl.ld_extra = sp["down_ld"]             # 下坡前看遠 0.15 m

3. 算前輪和速度。卡住時前輪維持不動，只算速度。

if self.state == RUN and not stuck:
    fwa = self.ctl.steer(res, self.ctl.v, t)
    v = self.ctl.speed(res, dt, t)
elif self.state == RUN:
    v = self.ctl.speed(res, dt, t)                # 卡住：前輪不動
elif self.state == LOST:
    v = self.ctl.ramp(self.v_lost, dt)            # 維持轉角、減速
else:
    v = 0.0                                       # IDLE / STOP

4. 卡住加速、爬坡、限速。順序很重要：先加卡住加速，再套上限。

extra = self.stall.update(frame, t, driving, fwa)  # 卡住要加多少 %
self.yaw.update(frame, t)
floor, cap = self.hill.update(self.stall, t, driving)
self.det.only_left = self.hill.active              # 爬坡時只信左線
if 坡頂到路口或下坡 and v > down_v:
    v = down_v                                     # 30%
if cap is not None and v > cap:
    v = cap
if extra:
    v = min(100.0, v + extra, total_max if cap is None else cap)
if floor is not None and v < floor:
    v = floor                                      # 爬坡最低 50%

5. 路段限制、路口動作、後輪。路口動作回傳非 None 時，直接蓋掉前面算的前輪和速度。

ramp = self.junc.ramp_steer(fwa, self.hill.active, t, self.yaw, frame)
if self.state == RUN and self.hill.active:
    fwa = ramp                                     # 坡道：限制 ±18° + 右線保護
elif self.state == RUN:
    fwa = self.junc.post_limit(fwa, t)             # 下坡前：右 12° / 左 4°
jf, jv = self.junc.update(fwa, self.hill.active, self.stall.active, t, ...)
if jf is not None:
    fwa, v, extra = jf, jv, 0.0                    # 左轉 / 直走 / 對準 / 右轉
if extra or (self.hill.active and jf is None):
    bwl = bwr = v                                  # 卡住或爬坡：兩輪同速
else:
    bwl, bwr = self.ctl.wheels(v, fwa)             # 差速
return (fwa, bwl, bwr)

vision.py：找線與算中線

process() 先用 lane_view_check.analyse() 找出左右白線的像素，再換成車身座標（公尺），擬合出中線。中線係數 (a, b, c) 代表 y = a·x² + b·x + c，x 是往前、y 是往左。

pts = self._centerline(r["_left"], r["_right"], res)
if self._jump(pts, res):                          # 爬坡：一張跳太多先不信
    return res
coef = np.polyfit(x, y, 2)
coef = smooth * 上一張 + (1 - smooth) * coef      # smooth = 0.5
res.offset = polyval(coef, x0)                    # 最近處中線位置 = 偏移
res.heading = atan(2a·x0 + b)
res.curvature = 2a / (1 + slope²)^1.5

yaw.py：車頭角度

沒有 IMU，用畫面上方 110 列（背景）做相位相關，算出左右位移幾個像素，換成角度累加。

def update(self, frame, t):
    g = gray(resize(frame[:110], (320, 55)))
    (dx, _), _ = cv2.phaseCorrelate(self.prev, g)
    if abs(dx) < 30:                               # 太大當雜訊
        self.value += dx / 320 * 70.0              # 像素 → 度（水平視角 70°）
    self.prev = g

def ref(self, t):
    # 最近 3 秒到 0.5 秒前的平均：坡道上車頭會晃，取平均才是坡道方向
    return mean(v for tt, v in self.hist if t - tt >= 0.5)

這個值會慢慢漂移，所以只拿來量「短時間內轉了幾度」，每次路口都重新取基準 yaw0。

link.py：通訊

獨立執行緒固定每 50 ms 送一次最新指令，同時讀 BMduino 回傳的 STA。主迴圈只更新指令，不等通訊。

def _loop(self):
    nxt = time.time()
    while self._running:
        cmd = self.cmd                             # 最新的 (fwa, bwl, bwr)
        self.link.send(*cmd)                       # CMD 封包，含檢查碼
        self.link.poll()                           # 讀 STA，更新 sta_time
        nxt += self.period
        time.sleep(max(0.0, nxt - time.time()))

def sta_age(self):
    return time.time() - self.link.sta_time        # 超過 0.5 秒 → Pilot 停車
