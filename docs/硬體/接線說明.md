# 硬體接線

接線依 [電路圖](電路圖.jpg)（`0803.kicad_sch`）。

| 訊號 | 從 | 到 |
|---|---|---|
| UART TX | Orin Pin 8 → 74HC125（1A → 1Y） | BMduino D20 / RX1 |
| UART RX | BMduino D21 / TX1（電路圖上為直接相連，⚠ 見下方注意事項） | Orin Pin 10 |
| GND | Orin Pin 6 | BMduino GND（一定要共地） |
| I2C | BMduino SDA / SCL | PCA9685（位址 0x40） |
| ENA / ENB | BMduino D8 / D9 → 74LS14（兩次反相） | DRV1011 ENA / ENB |
| IN1 / IN2 | PCA9685 CH4 / CH5 | DRV1011 IN1 / IN2（馬達 1） |
| IN3 / IN4 | PCA9685 CH6 / CH7 | DRV1011 IN3 / IN4（馬達 2） |
| 前輪舵機 | PCA9685 CH15（原本 CH0，2026-11-01 改接；零點 1520µs，行程 1100~1920µs） | 舵機訊號線 |
| 馬達 1 / 2 | DRV1011 OUT1-2 / OUT3-4 | 馬達 MOTOR− / MOTOR+ |
| 編碼器 A / B | 馬達 ENC_A、ENC_B | BMduino D5、D4 / D7、D6（尚未使用） |

注意事項：

- Orin 的 GPIO 是 **3.3V**。電路圖上 BMduino TX1 直接接到 Orin Pin 10，若 BMduino 的 I/O 是 5V，必須加分壓電阻或 5V 耐壓的轉換 IC（例如 74LVC125），否則可能燒壞 Orin 的 RX。
- 74HC125 的 `OE` 是低電位致能，要接 GND 才會導通（腳位見 [74HC125.jpg](74HC125.jpg)）。
- 馬達的 MOTOR± 和編碼器的線不可接錯，12V 接到編碼器會直接燒毀。
